# spring-react-products-filtering
 
![image](https://github.com/user-attachments/assets/1855fe55-c60c-4035-879a-2a9f2d9fe74d)
very simple full-stack application featuring a Spring Boot backend and React frontend. The backend provides a RESTful API to filter and sort products by category, producer, price, name, and promotion status, using a repository-based data layer. The frontend offers an interactive UI with dropdowns, search input, and a product grid, dynamically fetching and displaying filtered results from the API.
